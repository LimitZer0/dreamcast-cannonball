QRLeaderboard

Make a leaderboard pass for your Dreamcast memory card

Games that support QRLeaderboard offer score submission only when a pass is on a memory card. This page makes a pass for this site's leaderboard.

1. Memory card image (optional)

To add the pass to a memory card image you already use (Flycast, VM2, VMU Pro…), drop that image here. Its saves are kept. Otherwise you get a fresh card with just the pass.

Drop a 128 KB .bin memory card image, or click to choose one

2. Make it

  • QRLeaderboard_setup.cdi
    Setup disc for a real Dreamcast (GDEMU, burned CD). Boot it, pick a memory card, press A.
  • QRLeaderboard_vmu.bin
    Memory card image with the pass, for Flycast (as vmu_save_A1.bin) or SD-card memory cards.
  • QRLEADER.VMSQRLEADER.VMIQRLEADERBRD.DCI
    The pass as a single save file, for memory card managers (VMS + VMI pair, or DCI).

Everything is made on this page; nothing is uploaded. The pass takes 2 blocks and shows as “QRLeaderboard” in the memory card menu.
